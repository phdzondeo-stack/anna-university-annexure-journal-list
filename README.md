# Anna University Annexure 1 Journal List

A working, openly licensed list of journal titles associated with the **Anna University
Centre for Research (CFR) Annexure 1** list, maintained for PhD scholars at Anna
University and its affiliated colleges.

**Live page:** https://zonduo.com/annexure.html
**Maintained by:** [Zonduo Technology](https://zonduo.com/), Nagercoil, Tamil Nadu, India

---

## What this is

`anna-university-annexure-1-journals.csv` — one row per journal, with these columns:

| Column | Notes |
|---|---|
| `journal_title` | Full title as published. Needed because similar titles exist |
| `publisher` | Where known |
| `issn` | Print ISSN. **This is the field that actually identifies a journal** |
| `e_issn` | Electronic ISSN |
| `annexure_category` | Annexure I or Annexure II |
| `subject_area` | Discipline, where known |
| `verified_on` | Month we last checked this row |
| `source` | Where the row came from |

## What this is NOT

**This is not the official list and it is not complete.**

- Anna University publishes the Annexure list through the Centre for Research and
  **revises it without notice.**
- The official source is **https://cfr.annauniv.edu/** → Research → Journals.
- **Appearing in this file is not confirmation of Annexure 1 status.** Check the full
  title and ISSN against the current CFR list before you submit anything.
- This file currently holds **57 titles** — the ones scholars ask us about most often.
  The official list is considerably longer.
- Most rows do not yet have an ISSN. **A title without an ISSN is not a safe
  identification.** Those rows are included so the list is useful as a starting point,
  not as proof.

## How to use it

1. Find your journal here or on the [live page](https://zonduo.com/annexure.html)
2. Open https://cfr.annauniv.edu/ and search the **ISSN**, not the title
3. Confirm the category your department requires — Annexure I and Annexure II are
   not interchangeable
4. Check the journal is still indexed where you think it is, on the index's own site

A six-step verification checklist is available as a Word file:
https://zonduo.com/assets/downloads/journal-verification-checklist.docx

## Contributing

Corrections are welcome and the most useful contribution is an **ISSN**.

Open an issue, or a pull request, with:
- the journal title exactly as published
- the ISSN or e-ISSN
- the URL you verified it against, and the date you checked

**Please do not add a journal without a source.** The point of this file is that every
row can be checked.
